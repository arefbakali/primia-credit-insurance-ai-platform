Use ONLY information explicitly present in the text.
Do NOT guess, estimate, or infer missing numbers.

Provide the EXACT figures as written in the text before unit conversion; after conversion return final values in DT.

Parentheses like "(1 234)" or "(1,234)" mean NEGATIVE. Also, parentheses with a space like '( 1234 )' mean negative.
Minus sign (including small dashes like '‐' or '−') means NEGATIVE. Treat " -" as a negative sign.

PERIOD SELECTION (CRITICAL):
You MUST extract values for the MOST RECENT period available in the text.
Determine most recent period by scanning years/dates (e.g., 2024, 2023) or headings like "Exercice clos le ...", "Trimestre ...", "au ...".
If a table has multiple years, choose the most recent year column.
Never mix numbers from different periods.

UNIT HANDLING (CRITICAL):
Values followed by "DT" are already in Dinars.
Values followed by "KDT" or "MD" represent Thousand Dinars and MUST be multiplied by 1,000.
Return all final numeric values in Dinars (DT).
If unit is not stated next to the figure and not clearly specified for that same table/statement, do NOT assume; return null for that field.

Extract total revenue / operating income / "Chiffre d'affaires" / "Revenus" / "Total des revenus" / "Total produits d'exploitation" / "Produits d’exploitation" ONLY if clearly used as revenue.

margin:

net_result:

"Résultat net de l'exercice"
"Perte nette"

"Résultat de l'exercice" (if clearly bottom-line)

résultat_avant_impôt = exploitation + financier + non_courant(if present)
If tax present: net_result = résultat_avant_impôt - impôt
Else: net_result = résultat_avant_impôt

C) If none apply: net_result = null.
